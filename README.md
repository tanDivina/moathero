# MoatHero 🏰 — The AI Search & LLM Consensus Optimizer

MoatHero is a premium, clinical brand authority optimizer that tracks, audits, and expands your brand's presence across AI search engines, LLM Overviews, and conversational search platforms. Built for the modern web, it provides real-time comparative alignments and actionable, Gemini-driven bio optimizations to protect and boost your brand's citation consensus.

## 🚀 Key Features

1. **Brand Consensus Audit** — Scans conversational search datasets to analyze alignment, sentiment, and share-of-voice (SoV).
2. **Active Telemetry & Delta Snapshotting** — Captures your baseline consensus scores and tracks real-time improvements (e.g. `+33% Gain`) after optimization.
3. **Gemini AI Bio Proposals** — Generates SEO-optimized, highly cited bio structures to inject directly into your HTML schemas and social metadata.
4. **Cloud Firestore Snapshots** — Stores baseline and comparative telemetry snapshots under `/users/{userId}/snapshots` for deep historical analysis.
5. **Interactive Case Study Cards** — Composes shareable promotional copy comparing baseline vs. current rankings to generate immediate social proof.

## 🛠️ Technology Stack

* **Core Framework:** React 19, TypeScript, Vite
* **Styling & Motion:** TailwindCSS, Lucide Vector Icons, CSS group-hover micro-animations
* **Backend & Storage:** Vercel Serverless Functions (`/api`), Cloud Firestore
* **Deployment:** Vercel

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) and [pnpm](https://pnpm.io/) installed.

### Installation

Clone the repository and install dependencies:

```bash
pnpm install
```

### Run Locally

Start the Vite development server:

```bash
pnpm run dev
```

### Production Build

Compile the production bundle and run static diagnostic audits:

```bash
pnpm run build
```
